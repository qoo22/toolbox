# ToolBox（PDF ツール）README

ブラウザだけで動く PDF 変換・編集ツールです。
ファイルは **利用者のPCのブラウザ内だけで処理** され、どこにも送信されません。

| 項目 | 内容 |
|---|---|
| 作成者・管理者 | 佐々木 尊亮（Claude Code で作成） |
| 公開URL | https://qoo22.github.io/pdf/ （※公開の扱いは「6. 運用ルール」参照） |
| ローカル版 | このフォルダ（`サイトを起動.bat` で起動） |
| 想定利用者 | 社内の営業メンバー |
| 主な用途 | PDF の結合・圧縮・分割、PDF⇔画像の変換 |
| 最終更新 | 2026-10-21（脆弱性のある部品をすべて更新・置き換え。詳細は SECURITY.md） |

## 1. できること（機能一覧）

### PDF 編集
| 機能 | 内容 | 主なオプション |
|---|---|---|
| PDF 結合 | 複数の PDF を 1 つにまとめる | 並べ替え（ドラッグ／↑↓）、結合後に圧縮も可 |
| PDF 分割 | 指定ページを抜き出す／全ページを 1 枚ずつに分ける（ZIP） | ページ範囲 例 `1-3,5` |
| PDF 圧縮 | ファイルサイズを小さくする | 5 段階（下記参照） |
| PDF 回転 | 全ページを回転 | 右90°／180°／左90° |
| ページ番号追加 | 各ページに番号を入れる | 位置（下中央・右下・左下・上中央）、形式 `1 / 10` または `1` |

### PDF から変換
| 機能 | 内容 | 注意 |
|---|---|---|
| PDF → JPG / PNG | 各ページを画像に。複数ページは ZIP | 解像度 標準／2倍／3倍 |
| PDF → Word | 文字だけ取り出して .docx に | レイアウト・画像は再現しない |
| PDF → Excel | 文字を取り出し、1ページ＝1シートの .xlsx に | 表の罫線・書式は再現しない |
| PDF → PowerPoint | 各ページを画像として 1 スライドずつ貼る | スライド上で文字は編集できない |
| PDF → HTML | 文字を取り出して HTML に | 見た目は再現しない |

### PDF に変換
| 機能 | 内容 | 注意 |
|---|---|---|
| JPG / PNG → PDF | 画像を 1 枚 1 ページで PDF に | 並べ替え可 |
| Word → PDF | .docx を PDF に | 古い .doc は不可。レイアウトは簡易再現 |
| Excel → PDF | .xlsx / .xls / .csv を PDF に | シートごとに改ページ。書式は簡易再現 |
| PowerPoint → PDF | **未実装（準備中）** | |
| PDF のパスワード設定・解除 | **未実装（準備中）** | |

### PDF 以外（おまけ機能）
動画・音声の切り取り／結合／変換、画像形式の変換、ZIP 作成・解凍、画面録画、ボイスレコーダー、音声読み上げ。
業務の主目的ではないため、詳細は本書では省略します。

## 2. 使い方

1. https://qoo22.github.io/pdf/ を開く（またはローカル版を起動）
2. 上のメニューから使いたいツールを選ぶ
3. ファイルをドラッグ＆ドロップ（またはクリックして選択）
4. 必要ならオプションを選び、実行ボタン（「結合」「圧縮」など）を押す
5. できたファイルをダウンロード

### PDF 圧縮のレベル
| レベル | 動き | 向いている PDF |
|---|---|---|
| 構造のみ最適化 | 中身はそのまま、ファイルの内部構造だけ整理 | 劣化させたくないとき |
| 軽め／標準／強め | 文字のあるページはそのまま残し、画像だけのページ（スキャン・写真）を JPEG にして縮める | スキャンした書類、写真の多い資料 |
| 最大 | 全ページを画像にして縮める | とにかく小さくしたいとき（**文字がぼやけ、文字検索・コピーもできなくなる**） |

- 文字が中心の PDF は、もともと小さいのでほとんど縮みません（その場合は元のまま出力）。
- 「文字のあるページ」の判定は、ページ内の文字が 20 字以上あるかどうかで行っています。

### ローカル版の起動方法（インターネットの公開URLを使わない場合）
1. このフォルダの `サイトを起動.bat` をダブルクリック
2. ブラウザで `http://localhost:8765/` が開く
3. 終わったら黒い画面（PowerShell）を閉じる

※ `index.html` を直接ダブルクリックで開くと、PDF 機能を含むほとんどの機能が動きません。必ず `サイトを起動.bat` から開いてください。

## 3. 安全性（データの扱い）

- **ファイルはサーバーに送信されません。** すべての処理は利用者のブラウザの中（JavaScript）で行います。
  - コード内に外部へデータを送る処理（`fetch`・`XMLHttpRequest`・`sendBeacon` など）はありません（2026-10-20 確認）。
  - 使っているライブラリはすべて `vendor/` フォルダに同梱しており、外部の CDN からは読み込みません。
  - さらに `index.html` に CSP（Content-Security-Policy）を入れてあり、**外部サイトへの通信や外部からの読み込みはブラウザが拒否します**。万一プログラムに問題があっても、データを外へ送れません。
  - 確認の手順と結果は `SECURITY.md` にまとめています。
- 公開URL（GitHub Pages）から開いた場合、**ページ本体（HTML・JS）をダウンロードするための通信だけ** が発生します。処理するファイルの中身は含まれません。
- 例外：「音声合成（読み上げ）」で Chrome の「Google ○○」という声を選ぶと、読み上げる文章が Google のサーバーに送られることがあります。**社内情報の読み上げには使わないでください。**
- 画面録画・カメラ・マイク機能は、ブラウザの許可を求める画面が出たときだけ動きます。録画データも送信されません。
- パスワード付き PDF の解除機能はありません（準備中のまま）。

## 4. 仕組み（保守する人向け）

### ファイル構成
```
PDF/
├─ index.html        … 画面とすべての処理（1ファイルに全部入り）
├─ serve.ps1         … ローカル版用の簡易Webサーバー（Windows 標準の HttpListener、localhost のみ）
├─ サイトを起動.bat  … serve.ps1 を起動してブラウザを開く
├─ README.md         … 本書
├─ SECURITY.md       … セキュリティ確認の結果
└─ vendor/           … 外部ライブラリ（同梱・改変なし）
```

### セキュリティ上の決まりごと（修正するときに壊さないこと）
- `<head>` の CSP の行は消さない。外部の URL から読み込む部品を足さない（部品は必ず `vendor/` に置く）。
- pdf.js は `<script type="module">` で読み込み、`pdfjsLib.getDocument` を包み直している。この包みで、文字データなどの読み込み先を `vendor/pdfjs/` に固定し、PDF 内のプログラムを実行しない設定（`enableScripting:false` など）を強制している。この部分は消さない。
- 部品を更新したら、`SECURITY.md` の版の表と確認結果を更新する。3 か月ごとの定期確認は `SECURITY.md`「6. 定期確認」に従う。

### 使用ライブラリ（`vendor/`）
版と脆弱性の確認結果は `SECURITY.md` を参照。

| ファイル | 役割 |
|---|---|
| pdf-lib.min.js | PDF の結合・分割・回転・ページ番号・画像→PDF、Word/Excel→PDF のページ作成 |
| pdfjs/（pdf.js 6.4.299） | PDF の描画（画像化）と文字の取り出し。`cmaps/` 等は日本語 PDF 用の文字データ |
| html2canvas.min.js | Word/Excel の内容を画像にする（Word/Excel → PDF で使用） |
| jszip.min.js | 複数ファイルを ZIP にまとめる |
| mammoth.min.js | Word（.docx）を読む |
| xlsx.full.min.js（SheetJS） | Excel・CSV を読む・書く |
| pptxgen.bundle.js | PowerPoint を作る |
| ffmpeg*.js / ffmpeg-core.wasm | 動画・音声の処理（使うときだけ読み込み） |

### コードの構造（index.html）
- `const TOOLS = { ... }` … ツール 1 つ＝1 項目。`name`（表示名）、`desc`（説明）、`accept`（受け付けるファイル）、`options`（選択肢）、`run()`（実際の処理）を持つ。
- `const CATEGORIES = [ ... ]` … 上部メニューの並び。
- `compressPdfBytes()` … 圧縮処理。圧縮レベルの設定は `PDF_LEVELS`。
- `type:"coming"` のツールは「準備中」と表示されるだけで処理はない。

### ツールを追加・修正するとき
1. `TOOLS` に項目を追加（既存のツールをコピーして書き換えるのが早い）
2. `CATEGORIES` のメニューに ID を追加
3. ローカル版で動作確認（下のチェックリスト）
4. 問題なければ反映（「6. 運用ルール」に従う）

### 動作確認チェックリスト
- [ ] 2つ以上の PDF を結合できる／順番が反映される
- [ ] `1-3,5` で 4 ページ抜き出せる／全ページ分割で ZIP が出る
- [ ] スキャン PDF を「標準」で圧縮すると小さくなる
- [ ] 文字の PDF を圧縮しても文字がくっきりしている
- [ ] PDF → JPG/PNG で全ページが画像になる
- [ ] JPG/PNG → PDF で順番どおりにページになる

## 5. 既知の制限・トラブル時

| 症状 | 原因・対処 |
|---|---|
| パスワード付き PDF が開けない／結果がおかしい | 非対応。パスワードを外してから使う |
| 大きな PDF（数百ページ・数百MB）で止まる | ブラウザのメモリ不足。ページを分けて処理する |
| Word/Excel → PDF の見た目が崩れる | 簡易変換のため。きれいに出したいときは Word/Excel の「名前を付けて保存 → PDF」を使う |
| PDF → Word/Excel で表やレイアウトが崩れる | 文字だけを取り出す仕様 |
| 動かない・エラーが出る | 管理者（佐々木）に、使ったツール名・ファイルの種類・エラー文を連絡 |

**ツールが使えなくなっても業務が止まらないよう、主要機能は CubePDF Utility（全社許可済み）でも代替できます。**（次の表）

| 機能 | 本ツール | CubePDF Utility |
|---|---|---|
| 結合・分割・ページ抽出・回転 | ○ | ○ |
| 画像（JPG/PNG）→ PDF | ○ | ○（PDF を開いてから「挿入」で画像を追加） |
| PDF → PNG | ○ | ○ |
| PDF → JPG | ○ | ×（PNG のみ） |
| **PDF 圧縮（スキャン・写真の画像を縮める）** | ○ | ×（設定「重複リソースを削除」でフォント等の重複を省くだけ。画像は縮まない） |
| ページ番号追加 | ○ | × |
| PDF → Word/Excel/PPT/HTML | ○（文字のみ） | × |
| Word/Excel → PDF | ○（簡易） | ×（Office 本体の PDF 保存で代替可） |
| パスワード設定 | × | ○ |

## 6. 運用ルール

社内ガイドライン「Claudeなどの有料版AIツール利用ガイドライン」に沿って運用します。

- **鉄則②（外部公開）**：GitHub Pages での公開は、システム本部の承認を得るまで停止／限定する。承認が得られない場合はローカル版のみで運用する。
- **鉄則③（保守運用）**：チームへの展開は、稟議で保守運用の体制（担当者・引き継ぎ先）を決めてから行う。
  - 管理者：佐々木 尊亮
  - 引き継ぎ先：（稟議で決定）
  - 異動・退職時：下の「引き継ぎ手順」に従う。引き継げない場合は利用を停止し、CubePDF Utility に切り替える。
- 修正したときは、本 README の「最終更新」と該当箇所を更新する。

### 引き継ぎ手順（管理者が異動・退職するとき）

**渡すもの**
| もの | 場所 |
|---|---|
| コード一式（index.html・vendor/・起動用ファイル） | このフォルダ（`PDF`） |
| 本 README・SECURITY.md | このフォルダ |
| 公開版がある場合は GitHub リポジトリの管理権限 | GitHub（リポジトリ qoo22/pdf） |
| 利用者の一覧（誰に案内したか） | 管理者が把握しているもの |

**手順**
1. 退任の 2 週間前までに、引き継ぎ先と上長に連絡する
2. 引き継ぎ先にこのフォルダを渡す（共有ドライブ等、会社管理の場所へ）
3. 引き継ぎ先と一緒に、次を確認する
   - [ ] `サイトを起動.bat` で起動できる
   - [ ] README「動作確認チェックリスト」が全部通る
   - [ ] SECURITY.md「確認の手順」で外部通信がないことを確認できる
4. 公開版がある場合は、GitHub の管理権限を引き継ぎ先に移す。移せない場合は公開を停止する
5. 本 README の「管理者」と「変更履歴」を書き換える
6. 利用者に、新しい問い合わせ先を案内する

**引き継ぎ先が見つからないとき**
1. 利用者に「CubePDF Utility に切り替える」と案内する（切り替え方は 5 章の表）
2. 公開版がある場合は停止する（GitHub リポジトリの Settings → Pages）
3. 配布したローカル版は、利用者に削除を依頼する
